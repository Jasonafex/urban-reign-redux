# Urban Reign Redux

A community mod project by **Jasonafex** for Urban Reign. It includes character replacements, optional music and menu artwork, a dedicated Windows mod launcher, and an optional editor for creating new packs.

**Public release in preparation.** Screenshots and final download links will be added before release. The replacement intro video is still in production.

## Project page

Visit the [Urban Reign Redux website](https://jasonafex.github.io/urban-reign-redux/) for features, installation guidance, screenshots and release status.

## Packages

- **Mod launcher + launcher packs:** select and apply ready-to-use mods to your own supported ISO.
- **Optional editor:** preview and prepare models, textures and audio, then export launcher-ready packs.

The launcher supports **Clone**, which creates `Name-modded.iso`, and **Overwrite**, which keeps a recoverable original backup. Redux Music and Redux UI & Intro are independent selectable packs. A game ISO is not included.

See [PUBLISHING.md](PUBLISHING.md) for release preparation, screenshot replacement, Nexus Mods automation and TekkenMods guidance.
