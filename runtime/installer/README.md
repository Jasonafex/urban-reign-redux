# Automatic installer downloads

Players: **[Download Auto-Installer](https://github.com/Jasonafex/urban-reign-redux/releases/latest/download/Auto-Installer.exe)**.

The installer reads a bundled copy of this catalog and downloads only the selected packages, checking their sizes and SHA-256 hashes. Core presentation is required; Editor is optional and off by default. Character packages contain the matching current model patch and HD textures.

GitHub release assets are flat, not folders. The component release is storage for automatic downloads; no manual download or extraction is needed. Run the installer again to change your character selection. Existing edited source mods are preserved.
