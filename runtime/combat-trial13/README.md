# Trial 13 combat implementation snapshot

Source snapshot corresponding to the September 29 local combat playtest. See [patch notes](../../docs/patch-notes/2026-09-29-combat-playtest.md).

These modules are part of the private asset-authoring workspace, not a standalone consumer installer. Building them requires the historical workspace layout, legally supplied game data, locally extracted animation banks/manifests and authoring dependencies. Those assets and prerequisites are intentionally not bundled here. The relative paths in the scripts describe that workspace.

No ISO, extracted game binary, model, texture, sound, animation bank, save state, credential or personal runtime log is included. Do not run these scripts against an arbitrary game image. The public installer remains at its previous release.
