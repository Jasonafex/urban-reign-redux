How installation works ↓

GET STARTED

From download
to your next fight.

  1. 01

    Extract the release

    Keep the launcher installer and its mods folder beside each other, then run the installer.

  2. 02

    Choose your ISO and mods

    Select a supported original Urban Reign ISO. Choose Clone to make a separate modded copy beside it, or Overwrite to replace it with a recoverable backup.

  3. 03

    Apply, then play

    Let the loader finish applying and verifying the changes. Open the resulting ISO in your usual game setup.

What do I need?

A Windows PC, your own supported Urban Reign ISO, the launcher and compatible mod packs. The launcher checks the original image before building. Release notes will identify tested game revisions and any remaining issues.

Can I undo the changes?

Yes. Use Restore original. Keep the original ISO or the .iso.original backup, and the accompanying .studio.json record. Clone mode leaves the selected original untouched.

Do I need the editor to play?

No. The standalone loader uses ready-to-apply mod packs. The editor is for making or adjusting mods.
